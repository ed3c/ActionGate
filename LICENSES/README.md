# Third-party licenses and notices

No third-party source import is currently admitted.

When `.provenance/upstreams.lock.json` admits an upstream, add the exact observed LICENSE and NOTICE material under an upstream-specific directory and bind its digest in the lock. Do not add a license file from a different tag, branch or latest default branch.

The root `LICENSE` governs original ActionGate material only to the extent the contributor has authority to license it.
