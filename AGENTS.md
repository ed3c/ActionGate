## Independent source and clean-room law

For source, dependency, generated-code, import, license or release work, `PROVENANCE.md` and `docs/provenance/AGENTS.md` are mandatory.

- Do not invent a Fork/upstream relationship.
- `DERIVED_PUBLIC_UPSTREAM` or `VENDOR_IMPORT` requires exact public repository, commit, tree, license digest and source-to-local path mapping.
- `DEPENDENCY_ONLY` still requires exact revision, license/NOTICE and SBOM.
- `CLEAN_ROOM_REIMPLEMENTATION` requires a frozen public contract and an independent implementation receipt.
- Every commit must carry DCO sign-off.
- Implementation Sessions may consume only the active task's enumerated public sources.
- Employer source, internal documents, private protocols, internal test vectors, customer data, credentials, company equipment/CI and private prompt context are forbidden.
- Suspicious similarity stops the atom.
- A permissive license or technical clean-room PASS is not employment, patent, legal or business-overlap clearance.
- Human declarations cannot be fabricated or checked by an Agent.
- Release remains blocked while `.provenance/release-gate.json` retains blockers.

## Article/PDF law

Source material can be classified, retained as a hypothesis, rejected as an overclaim or routed to an evidence owner. It cannot prove implementation, runtime, hardware, current policy/legal rights, user value, payment, merge, release or production. Do not silently replace unsupported numbers.

## Stack law

- one writer per mutable subject;
- dedicated branch/worktree and disjoint path/resource lease;
- sibling branches stay siblings absent real unmerged-byte dependency;
- parent movement makes affected receipts stale;
- no silent rebase/fast-forward of non-empty Worker branches;
- review-only Shadow is not a Git parent;
- merge/release/production/visibility/legal/security/authority widening are Human-owned.

## Handoff contract

Every packet binds repository, Issue, stage/atom, exact base/head/tree, branch/PR, lease, private-context state without locators, input receipts, outputs, commands/exits, evidence lane/state, Shadow deltas/dissent, blockers, next entry condition and Human-owned operations.

No secrets, private URLs, stable device identifiers or private reasoning.

The technical queue remains `.actiongate/local-handoff-queue.json`. Provenance-specific external/Human transitions live in `.provenance/local-handoff-queue.json`; that queue has no ACTIVE item until a Human selects an upstream and supplies the required private declarations.

## Stop conditions

Stop on stale subject, missing task, false dependency, overlapping lease, private leakage, invented/unpinned upstream, unlocked import, license/SBOM drift, DCO failure, unsupported source claim promoted to fact, ambiguous canonicalization/signature payload, missing idempotency/replay/reconciliation, absent oracle, unavailable capability, semantic conflict, denominator shrinkage, unhandled late state, budget exhaustion or Human-owned operation.

## Evidence ceiling

Highest integrated main state remains merged control/source/handoff documentation. Draft language branches contain local-deterministic C01 implementation candidates, but C01 admission, physical devices, independent security/provenance review, user value, employment-IP/legal clearance, release and production remain unproven.
