# Provenance receipts

This directory stores redacted, exact-subject receipts only.

Allowed receipt classes:

- clean-room Session receipt;
- upstream baseline observation receipt;
- imported-path verification receipt;
- independent provenance review receipt;
- redacted outside-project review receipt;
- release-admission receipt.

Never store a private document URL, employment agreement, legal memo, customer identity, employer product detail, credential, device identifier, or private reasoning here.

No receipt is present at bootstrap because no upstream import, clean-room implementation Session, independent review, legal admission or release admission has occurred.
